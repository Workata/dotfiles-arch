# keybindings

- `SUPER` + `Q` - run terminal (`kitty`)
- `SUPER` + `C` - close window
- `SUPER` + `P` - run power menu (`wlogout`)
- `SUPER` + `L` - run screen lock (`hyperlock`)
- `SUPER` + `V` - toggle floating window
- `SUPER` + `SPACE` - run application launcher
- `SUPER` + `{number}` - switch workspace
- `PRINT` - printscreen
